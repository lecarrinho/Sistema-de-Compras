      Status de pedido

      Marque "Finalizado" para status que encerram o pedido (ex.: Entregue, Cancelado) — eles nunca ficam vermelhos por atraso.

        Backup dos dados (.json)

        Gera um arquivo .json com todos os pedidos e cadastros (formas de pagamento, tipos de frete e status). Escolha uma pasta fixa para os backups: a partir daí, salvar e carregar o último backup passam a usar essa pasta automaticamente, sem abrir a janela de seleção toda vez.

        Nenhuma pasta selecionada — os backups serão salvos onde você indicar a cada vez.

        Nenhum backup salvo neste navegador ainda.

        No Chrome e no Edge, é possível fixar uma pasta do computador para os backups. Em outros navegadores (Firefox, Safari), essa opção não é suportada: "Salvar backup" baixa o arquivo para a pasta de downloads padrão e "Carregar último backup" pede para você selecionar o arquivo manualmente.

        Aparência do sistema

        Escolha a cor de destaque e a combinação de fontes usadas em todo o sistema. A mudança é aplicada imediatamente e fica salva neste navegador.

        Os dados ficam salvos apenas neste navegador (armazenamento local do computador).
